CASTD on the web: see the step-by-step guide in the chat. Short version (Render):
1. Put this folder on GitHub.  2. Render > New > Web Service > pick the repo.
3. Build command: pip install -r requirements.txt   Start command: python trend_app.py
4. Choose the Free plan > Create. Open the link Render gives you.
Hugging Face Spaces: New Space > Docker > upload these files (the Dockerfile is included).

Google 3D globe: on Render add the Environment Variable GOOGLE_MAPS_API_KEY (your Google Maps key, restricted to your website). Never put the key in a file on GitHub.
